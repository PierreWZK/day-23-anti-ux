N° 06

Pourquoi ça ne va pas
L’icône corbeille est collée à l’icône crayon. Un clic, le fichier disparaît : ni confirmation, ni annulation possible.
La règle à retenir
Pour une suppression réversible : supprimer tout de suite, mais proposer « Annuler » quelques secondes. Pour une suppression définitive : une confirmation qui nomme l’élément.

Version corrigée

function supprimer(item) {
  item.remove();
  afficherToast(item.nom + ' supprimé', {
    action: 'Annuler',
    onAction: () => restaurer(item),
    duree: 8000,
  });
}
