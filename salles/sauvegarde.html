N° 26

Pourquoi ça ne va pas
À chaque pause dans la frappe, un voile « Sauvegarde en cours… » bloque l’éditeur. Les lettres tapées pendant ce temps sont perdues.
La règle à retenir
La sauvegarde automatique ne bloque jamais. Un statut discret (aria-live="polite") indique « Enregistrement… » puis « Enregistré à 14:02 ».
Référence
WCAG 4.1.3 · Messages d’état
Voir le code, avant et après

Version ratée

texte.addEventListener('input', debounce(async () => {
  voile.hidden = false;
  texte.disabled = true;   // bloque la frappe
  await sauvegarder();
  texte.disabled = false;
  voile.hidden = true;
}, 800));

Version corrigée

<p id="statut" role="status"></p>
<script>
  texte.addEventListener('input', debounce(async () => {
    statut.textContent = 'Enregistrement…';
    await sauvegarder();
    statut.textContent = 'Enregistré à ' + heure();
  }, 800));
</script>
