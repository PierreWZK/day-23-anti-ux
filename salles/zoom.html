N° 05

Pourquoi ça ne va pas
Le bouton « + » zoome sans limite, il n’y a ni « − » ni réinitialisation, et le niveau n’est jamais affiché. Après trois clics, on ne voit plus qu’un pixel géant.
La règle à retenir
Un zoom borné (ici 100 à 300 %), avec « − », « + », « Réinitialiser », le niveau affiché, et un défilement pour explorer. Ne jamais bloquer le zoom natif (user-scalable=no).
Référence
WCAG 1.4.4 · Redimensionnement du texte
Voir le code, avant et après

Version ratée

<meta name="viewport"
  content="width=device-width, user-scalable=no">
plus.onclick = () => (zoom *= 1.8);

Version corrigée

const MIN = 1, MAX = 3, PAS = 0.25;
function zoomer(delta) {
  zoom = Math.min(MAX, Math.max(MIN, zoom + delta));
  carte.style.transform = 'scale(' + zoom + ')';
  niveau.value = Math.round(zoom * 100) + ' %';
  moins.disabled = zoom === MIN;
  plus.disabled = zoom === MAX;
}
