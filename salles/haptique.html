N° 02

Pourquoi ça ne va pas
Chaque touche du clavier PIN déclenche une longue vibration, et c’est le seul retour : aucun point ne se remplit. Les vibrations fatiguent, et les personnes qui les ont coupées ne savent plus où elles en sont.
La règle à retenir
Les vibrations restent rares, courtes et toujours doublées d’un retour visuel. Elles se désactivent.
Référence
Apple HIG · Playing haptics

Version ratée

touche.addEventListener('click', () => {
  navigator.vibrate(400); // à chaque touche
});

Version corrigée

touche.addEventListener('click', () => {
  remplirPoint();          // retour visuel d'abord
  if (codeComplet() && prefs.vibrer) {
    navigator.vibrate?.(20); // une seule, courte
  }
});
