N° 28

Pourquoi ça ne va pas
Après une pause, la session a expiré : retour à l’accueil, panier vide, il faut tout recommencer.
La règle à retenir
Prévenir avant l’expiration avec « Prolonger », puis, après reconnexion, revenir exactement à la même étape avec les mêmes données.
Référence
WCAG 2.2.5 · Nouvelle authentification
Voir le code, avant et après

Version ratée

if (sessionExpiree()) {
  location.href = '/'; // panier et étape perdus
}

Version corrigée

if (sessionExpiree()) {
  const reprise = encodeURIComponent(location.pathname);
  location.href = '/connexion?retour=' + reprise;
  // panier et étape conservés côté serveur
}
